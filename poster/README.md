# Poster source

This directory contains the public software-architecture poster source and local
Gemini theme files. The poster describes the computational framework and does
not embed restricted PPMI result figures.

Build locally with:

```bash
python scripts/build_poster.py
```

Generated `poster.pdf`, `build/`, and `figures/` artifacts are ignored. Any
PPMI-derived figure or interpretation requires the applicable DCI/DUA and
publication approval before dissemination.
